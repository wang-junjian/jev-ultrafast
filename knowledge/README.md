## 推荐阅读路径

- **15 分钟建立全局观**：01 → 05。
- **准备动手开发**：01 → 02 → 06，改到哪块再回头精读对应分篇。
- **改模型行为**：03 + 07（D1/D2）；**改浏览器层**：04 + 07（D3/D5）。

## 使用约定

- 行号引用格式为 `文件:行`（如 `agent.py:91`），均在 `jev_ultrafast/` 或仓库根目录下。
- 想验证任何结论：直接打开被引用的源码行；测试行为以 `tests/test_agent.py` 为准。
- 发现文档与代码不一致 → 代码是对的，请更新本文档（也欢迎顺手更新）。
